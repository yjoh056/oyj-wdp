디자인 시스템

톤앤 매너
이전 특별 전시와 연결되는 무드, 전시되는 곳의 특성에 맞춤. 공룡 모형 전시에 맞는 배경과 어울리는 UI 제작.
색채 계획
서식지의 무드인 풀숲을 살리는 화사한 컬러 사용. 주 사용층이 어린이인 점을 고려하여 단순하면서 컬러풀한 컬러감 사용.
Point Color
Base Color
폰트타입
파셜산스 · 태나단체 본문 격동고딕2 · 영문 Acumin Variable Concept
타이틀은 판화 스타일의 서체로 빈티지한 노트 느낌 강조, 본문은 깔끔하고 직각적인 고딕 계열로 정보 전달에 초점, 영문 학명은 명칭표기 특성을 고려해 이탤릭 고딕체 사용.

배경그래픽

Tool: Photoshop, ChatGPT — 화산과 야자수, 공룡이 어우러진 서식지 무드의 대형 배경 그래픽을 제작해 키오스크 존의 실제 벽면 그래픽으로 시공했다.

Kiosk

공룡백과사전

공룡 탐구(도감) → 공룡 퀴즈(실루엣 맞추기) — 다이노월드 특별전 키오스크 콘텐츠에 대한 호평으로, 내용과 단계를 수정해 상설전시로 재구성

Keyword
미니게임, 백과사전
Design Direction
공룡시대 어린이를 타겟으로 한 게임 모드 구성. 육식 공룡과 초식공룡의 배경을 다르게 하여 확실한 구분과 시각적 재미를 줌.
Visual Elements
유휴화면을 벽 실사와 같은 이미지로 설정, 탐구모드에서 공룡 배치 순서와 패널의 이미지를 일치시켜 아이들이 쉽게 공룡 이름과 특징을 연결 지을 수 있도록 설계.

화면설계서 · 전체 플로우

1회 실행 시 총 4문항으로 구성. 오답 시 피드백 팝업을 보여주고, 힌트 버튼으로 정답을 유추할 수 있도록 하여 아이들이 끝까지 몰입할 수 있게 구성. 정답을 확인한 뒤에는 다음 문항의 실루엣 화면으로 이어지며 이 과정을 4문항까지 반복.
탐구모드에서 본 공룡 배치 순서와 패널 이미지를 퀴즈 실루엣에 그대로 연결해 학습 효과를 높임.
