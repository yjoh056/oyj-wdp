전체 사용자 흐름

4종 키오스크의 진입부터 종료·자동 복귀까지의 흐름입니다. 점선은 분기와 예외 상태입니다.

Kiosk 1작곡 키오스크
  1. 시작
  2. 닉네임 입력
  3. 장르 선택
  4. 클래식 → 작곡가 스타일(1개)
  5. 가요 → 감정 키워드(1~3개)
  6. 음악 생성
  7. 완성곡 감상 · 저장
  8. QR 저장 · 공유
  9. 20초 후 처음으로
Kiosk 2뇌파측정 키오스크
  1. 시작
  2. 측정기 착용 안내
  3. 뇌파 측정(12초)
  4. 결과 4종
  5. 측정 실패 → 착용 안내로
Kiosk 3표정측정 키오스크
  1. 시작
  2. 이어폰 착용 안내
  3. 표정 분석(10초)
  4. 결과 6종
  5. 음악 종료 1분 후 처음으로
  6. 인식 실패 → 다시 시도
Kiosk 4Music Showcase
  1. 시작
  2. 내 음악 찾기 → 검색 → 검색 결과
  3. 음악 리스트(5곡씩)
  4. 항목 선택
  5. 재생하기
  6. 쇼케이스 재생
  7. 종료 후 처음으로

Kiosk 4의 검색은 Kiosk 1(누구나 작곡가)에서 등록한 닉네임·음악 제목으로 이어집니다.

Kiosk 1

작곡 키오스크

닉네임 입력 → 장르 선택 → 감정 키워드 선택(최대 3개) → 완성곡 감상

Keyword
키워드선택, 닉네임입력, 음악감상
Design Direction
복잡하지 않고 간단한 버튼 선택 단계로 작곡을 할 수 있는 컨셉. 선택과 관련된 설명위주의 레이아웃.
Visual Elements
키비주얼의 블랙대신 블루톤의 배경으로 가시성과 공간컬러 맞춤. 키오스크 유휴화면에 이미지로 구분.

화면설계서 · 전체 플로우

음악제목이 랜덤으로 송출된다는 기술적 문제점을 보완하기 위한 타이틀 배치

동작 규칙 · 자동 복귀

  • 닉네임 입력조건에 맞지 않으면 입력 버튼 비활성화, 입력하면 활성화. 중복·금지어는 팝업으로 안내하고, 닉네임 뒤 (1)은 자동 생성 기호로 표기
  • 선택 단계장르는 클래식이면 작곡가 스타일(1개), 가요면 감정 키워드(1~3개)를 선택. 선택하면 컬러가 바뀌고 다음 버튼 활성화
  • 처음으로 이동 시입력 단계에서는 닉네임 삭제. 생성 중에는 음악 재생은 하지 않고 전송은 계속 진행
  • 생성 완료 · 출력완료되면 저장하기 버튼 노출 및 문구 변경. 클래식은 자동연주 피아노, 가요는 스피커로 송출(최대 1일 보관)
  • QR 화면저장하기를 누르면 QR 화면으로 이동. 20초 카운트다운 후 처음 화면으로 자동 이동

예외 처리 팝업 & 입력 설계

Kiosk 2

뇌파측정 키오스크

측정기 착용 안내 → 뇌파 측정(로딩) → 결과 확인

Keyword
뇌파측정, 측정별결과도출
Design Direction
뇌파 측정기의 착용부터 측정까지 단계 안내. 각 키오스크 유휴화면에 이미지로 구분.
Visual Elements
키비주얼의 블랙대신 퍼플 톤으로 공간 컬러 맞춤.

화면설계서 · 전체 플로우

측정 시간 동안 사용자 이탈을 방지하고 몰입감을 유지하기 위해 시각적 피드백이 있는 측정 화면과 로딩 게이지를 제공.
음악 감상 중 시각적 지루함을 줄이고 몰입감을 높이기 위해 회전하는 CD 애니메이션 적용.

동작 규칙 · 자동 복귀

  • 측정뇌파 측정 12초 후 결과 화면으로 이동. 결과는 CD 이미지가 회전하는 애니메이션으로 제공
  • 측정 실패"측정기를 다시 착용해볼까요?" 팝업에서 버튼을 누르면 착용 안내 단계로 이동
  • 미반응 시30초 이상 반응이 없으면 첫 화면으로 이동
Kiosk 3

표정측정 키오스크

골전도 이어폰 착용 안내 → 표정 측정 → 결과에 따른 컬러 피드백

Keyword
표정 측정, 측정별결과도출
Design Direction
표정측정을 위한 안내, 골전도 이어폰 착용 안내, 각 키오스크 유휴화면에 이미지로 구분.
Visual Elements
앞의 키오스크 컬러와 유사한 시리즈로 컬러 지정. 표정 +- 정도에 따른 다른 컬러로 분석 결과에 따른 시각적 효과.

화면설계서 · 전체 플로우

측정 시간 동안 사용자 이탈을 방지하고 몰입감을 유지하기 위해 시각적 피드백이 있는 측정 화면과 로딩 게이지를 제공.
결과값에 따라 다른 색상과 게이지량에 차이를 두고 음량 게이지 형태의 애니메이션을 주어 음악을 들으면서 지루하지 않은 화면 구성.

동작 규칙 · 자동 복귀

  • 분석표정 분석 10초. 정면을 응시하도록 안내하고, 움직임이 많아 인식되지 않으면 재시도 화면 노출
  • 결과음악 종료 후 1분 뒤 처음 화면으로 자동 이동
  • 미반응 시착용 안내·인식 실패 화면에서 1분 후 처음으로 자동 이동
Kiosk 4

Music Showcase

음악 검색/신청 → 재생 리스트 확인 → 대형 쇼케이스 화면 송출

Keyword
음악플레이, 검색기능
Design Direction
플레이 중 정지나 뒤로 가기 버튼이 없어 리스트에서 직접 항목을 다시 선택하도록 유도. 두 기기에서 검색 기록이 공유될 수 있어, 검색 결과와 디자인을 각각 대응되도록 구성.
Visual Elements
뮤직 쇼케이스에서 음악을 전시하는 컨셉에 맞춰, 기존보다 더 화려하고 선명한 컬러 사용.

화면설계서 · 전체 플로우

사용자가 무대를 이용 중에 음악이 멈추지 않도록 조작 버튼을 제거하여 구성. 음악 재생 시간 동안 다른 사용자에게 남은 시간을 인지시킬 수 있도록 상단에 플레이 타임 게이지를 시각적으로 배치.
기다리는 동안 무대에 조명이 반짝이는 애니메이션을 적용하여 정적인 화면에 생동감을 부여하고 재생 중임을 직관적으로 전달.
음악이 끝날 때까지 되돌아갈 수 없는 구조와 터치 슬라이딩 UI를 고려하여, 선택 즉시 자동 재생되지 않도록 설정하고 '재생하기' 버튼을 별도로 노출하여 사용자 조작의 명확성과 편의성 향상.

동작 규칙 · 자동 복귀

  • 목록음악 리스트는 5곡씩 노출하고 스크롤로 이동. 한 번 터치하면 보라색 선택 상태, 한 번 더 누르면 재생
  • 재생음악이 끝나는 시간을 재생바로 안내. 재생 종료 후 처음 화면으로 자동 이동
  • 검색두 기기의 닉네임 중복 처리가 안 되므로, 같은 닉네임·제목이 2개 이상이면 검색 결과에 모두 노출
